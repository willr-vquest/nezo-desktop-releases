# Nezo desktop — releases

Download and update channel for the **Nezo desktop app**.

Installers are published on the [Releases](../../releases) page. Each release also carries a
`latest.yml`, which is the feed the app's built-in updater checks — so an installed copy keeps
itself up to date and you only download from here the first time.

This repository holds **no source code**. It exists so the update feed can be fetched without
authentication; the application source is maintained privately.

## Install

Download the latest `Nezo-Setup-<version>.exe` from [Releases](../../releases) and run it.
Windows only. The app updates itself from then on.
